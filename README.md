# Speak To Me

Speak To Me is an offline-first, child-safe, voice-powered SwiftUI iPad app for ages 3-6.

## Build

This repository uses XcodeGen to generate an Xcode project.

1. Install XcodeGen (`brew install xcodegen` on macOS).
2. Run `xcodegen generate` in the repository root.
3. Open `SpeakToMe.xcodeproj`.
4. Run on an iPad simulator or device.

## Privacy and Safety

- Offline-first gameplay
- No ads
- No external links in child-facing areas
- No in-app purchases
- No internet requirement for play

## Included

- Multi-child profiles
- Parent gate + parent dashboard
- 10 playable world areas
- Prompt -> Wait -> Model -> Mouth -> Attempt -> Reward -> Continue loop
- Local progress export (JSON and CSV)
